# 研究逻辑与验收约束（0.2）

日期：2026-10-10。本文说明当前可执行流程；历史截图、录屏和旧评测使用 0.1 的行为与指标。

## 需求是唯一任务依据

取消“研究主题 / 岗位描述”分类。原始需求贯穿规划、取证、回答、检查和修复，objective 只是辅助整理。岗位或招聘文本可以作为研究对象，不自动变成技能路线、求职或面试建议。

ResearchBrief 记录 original_request、as_of、scope、constraints、time_scope、output_requirements、freshness_required 和 allow_web_research。当前约束识别为有限规则与模型辅助，不是完整自然语言解析器；明确的“不联网”“不要搜索”“仅根据提供的材料”会禁止搜索和抓取。原始文本始终保留。supplied_text 单独承载用户材料，不能将需求指令本身当成外部证据。

规划只拆必要问题，最少 1 个，每问题 1–3 条查询；失败时退回完整原始问题，而不是虚构固定的比较、职业或背景分支。相对时间以运行 as_of 为参照，来源获取日期不能替代内容适用日期。

## 取证、补查与停止

1. 查询按问题轮转；跨查询去重合并 question_ids 和 queries，保留出处路径。
2. 每轮页面名额尽量覆盖未解答问题；给后续轮次保留名额，不把全部预算给首条查询。
3. 新补查候选可以替换满池中的旧候选，已取得的 SourceDocument 独立保留，不因候选淘汰丢失。
4. 清洗所有已获取正文：保留段落、标题、表格行和附录；长段落分块有重叠，位置指向清洗文本。没有固定“前 8000 字符”选材边界。
5. 在所有块上按词法相关性和问题/来源多样性选材。显式用户材料即使没有查询词重合也会进入候选。上下文不足会记录未入选相关片段数；“扫描过”不代表模型读过全部内容。
6. 逐问题评估充分性和冲突；只有摘要或不完整正文不能独自支持“充分”。时间限定回答要确认时间/版本适用性。需要全文概括但选材不完整时应保留缺口。
7. 缺口触发有限补查：新查询或尚未读取的候选仍可利用。证据充分、候选耗尽、预算或轮数耗尽时停止；明确记录原因。

下载限制按字节计，超过预算会标记 download_truncated，记录原因且不写入成功页面缓存。网页拦截、缺少正文、不支持类型均保留状态。搜索摘要单独存储，不冒充抓取成功正文。

EvidenceChunk 记录稳定 ID、URL、source_id、kind、正文位置、问题关联与时间信息。正文、摘要、Mock、用户材料具有不同的可信度含义；证据位置不是网页 HTML 的字节偏移。

## 回答与完成状态

回答必须遵守原始问题及排除项，事实段落引用具体证据 ID 和 URL。格式校验覆盖正文而不限定章节名；标题回显、参考文献列表不能制造“答案已引用”的假象。语义检查另外判断任务遵从、完整性及事实支持。

修复最多一次，继承原需求、证据、问题评估与表达策略；只有非空、结构问题不增加且语义检查通过才替换原报告。空响应、截断输出与非法 JSON 不会被当成成功答案。

本地降级仅输出资料摘录、证据限制和未解答问题。云端失败、部分搜索失败、没有证据、Mock 演示都不能被流程结束事件掩盖。完成状态详见 README；模型语义检查仍可能出错，completed 只代表通过当前质量门槛。

## 预算与费用

全部预算集中配置；循环、重试、修复有明确上限。单个请求在发送前检查上下文、总 Token、估算费用、时间和调用次数。输入不会为了满足上下文预算被静默裁断。瞬时网络错误最多重试一次，仍计入尝试次数；不知道实际 usage 的失败调用保留预算预留，但不会捏造已计费 Token。

价格是混合估值，搜索费用不包括在模型金额上限内。计时为协作式检查和 HTTP 操作超时，并非可以强制中止任意底层阻塞的硬截止。独立 Judge 评审有自己的记录、费用和预算，不改写原研究。

## 缓存、存储与评测

只缓存完整取得的页面正文，不缓存整个研究结果。缓存 TTL 与强制刷新有效；命中原文时沿用原始获取时间，不以当前时间伪装新抓取。每次研究和每次 Judge 各有独立 ID。

run_details 是完整研究状态的唯一数据源，run_index 用于列表，reviews 保存独立评审。旧 runs/trace_events 不删除、不用新写入覆盖，旧数据按 legacy 读取。每完成节点写快照，最终补齐持久化节点的结束轨迹；暂不自动续跑快照。

评测中“执行结束”“通过质量门槛”“预期错误/空结果处理”分别统计。关键词召回和任意来源数量配额不再决定完成。相同证据预算用于不同回答策略；Mock 只验证流程，不证明付费模型质量。旧版结果以历史口径保存，新 UI 只读取 schema_version=2。

## 回归场景

- 制造业研究需求不会改写成求职建议，排除项和时间范围保留。
- 8000 字符之后的关键证据可被选中，长段落尾部、表格、附录未被头部截断规则丢弃。
- 多问题取证、满候选池补查、有限重试与预算停止可复现。
- 全部抓取失败、领域外 Mock、空材料不会误报完成。
- 只有发布日期但适用性未知、存在冲突、仅有摘要不能悄悄通过质量门槛。
- 非法引用、正文无引用、空修复与空 Judge JSON 均受到检查。
- 缓存过期与刷新保持真实获取时间；历史记录可读取、Judge 不污染原记录。
- Streamlit Research / Evaluation 和用户材料模式有集成测试。

未覆盖的真实能力边界：词法选材不保证语义召回；HTML 清洗不支持 PDF、图片文字和动态渲染；同一模型的审查不是独立事实核验；尚无真实供应商端到端试验与人工盲评。
